# رواق العربية

موقع تعليمي ثابت (HTML / CSS / JavaScript) لتعلّم مهارات اللغة العربية:
القراءة والفهم، الإملاء، الصرف والتحويل، التراكيب، والتعبير والكتابة.

لا يحتاج الموقع إلى خادم ولا إلى قاعدة بيانات، ويمكن نشره على أي استضافة ملفات ثابتة.

## 2) ما يجب تعديله أولًا: `assets/js/config.js`

كل ما يخصّ هوية الموقع والتواصل والمواعيد موجود في ملف واحد.

### أ) رابط Google Meet

```js
meetLink: "",   // اتركه فارغًا لعرض زر «اطلب رابط الحصة»
```

استبدله برابط الغرفة:

```js
meetLink: "https://meet.google.com/abc-defg-hij",
```

عندها يتحوّل زر الحصة في كل الصفحات إلى «انضم إلى الحصة»، ويُضاف الرابط تلقائيًا
إلى حدث «أضف إلى تقويم Google».

### ب) بيانات المعلّم والتواصل

```js
teacher: {
  name: "أبو يوسف محمد عزان",
  role: "مدرّس اللغة العربية",
  bio: "…",
  email: "",     // مثال: "teacher@example.com"
  phone: "",     // مثال: "0612345678"
  whatsapp: "",  // مثال: "212612345678"
}
```

- عند إضافة `email` يظهر البريد في التذييل وصفحة «عن الموقع»، ويُرسل نموذج التواصل
  الرسالة عبر تطبيق البريد في جهاز الزائر (لا يوجد خادم).
- عند إضافة `phone` أو `whatsapp` يظهران في بطاقة التواصل.

### ج) مواعيد الحصص

```js
sessions: [
  { id: "s-reading", day: 0, time: "20:00", duration: 45, track: "reading", title: "…", desc: "…" },
  …
]
```

- `day`: `0` الأحد، `1` الاثنين … `6` السبت.
- `time`: 24 ساعة، بتوقيت جهاز الزائر.
- `track`: أحد معرّفات المسارات: `reading` / `imla` / `sarf` / `tarakib` / `writing`.

العدّاد التنازلي والحصة «القادمة» وروابط التقويم تُحسب تلقائيًا من هذه القائمة.

### د) ملفات التنزيل

```js
downloads: {
  docx: "assets/tests/الاختبار-المنزلي-الوحدة-الأولى.docx",
  pdf: "assets/tests/الاختبار-المنزلي-الوحدة-الأولى.pdf",
  paper1: "assets/tests/الورقة-الأولى.pdf",
  paper2: "assets/tests/الورقة-الثانية.pdf",
}
```

## 3) إضافة درس أو تمرين

### درس جديد

أضف عنصرًا إلى `window.SITE_LESSONS` في `assets/js/data-lessons.js`:

```js
{
  id: "my-lesson",            // معرّف لاتيني فريد بدون مسافات
  track: "imla",              // reading | imla | sarf | tarakib | writing
  title: "عنوان الدرس",
  subtitle: "سؤال يلخّص فائدة الدرس",
  level: "مبتدئ",             // مبتدئ | متوسط | متقدّم
  minutes: 12,
  summary: "جملة تظهر في بطاقة الدرس.",
  objectives: ["هدف أول", "هدف ثانٍ"],
  blocks: [ … ],
  quiz: "q-imla-1"            // معرّف تمرين موجود (اختياري)
}
```

أنواع الكتل المدعومة في `blocks`:

| النوع | الحقول |
|---|---|
| `p` | `text` |
| `h3` | `text` |
| `ul` / `ol` | `items` |
| `reading` | `title`، `paragraphs` |
| `table` | `head`، `rows` |
| `example` | `text` |
| `note` | `title`، `text` |
| `think` | `text` |
| `details` | `items: [{ q, a }]` |
| `keypoints` | `items` |

يمكن استخدام `**نص**` للتشديد داخل معظم الحقول النصية.

### تمرين جديد

أضف عنصرًا إلى `window.SITE_QUIZZES` في `assets/js/data-quizzes.js`:

```js
{
  id: "q-new",
  track: "sarf",
  title: "عنوان التمرين",
  desc: "وصف قصير",
  level: "متوسط",
  minutes: 6,
  passage: { title: "…", paragraphs: ["…"] },   // اختياري لنصوص القراءة
  questions: [
    { q: "نص السؤال", options: ["أ", "ب", "ج", "د"], answer: 0, explain: "سبب الإجابة" }
  ]
}
```

`answer` هو ترتيب الإجابة الصحيحة بدءًا من الصفر. تُحفظ أفضل نتيجة في متصفح الزائر.

### اختبار جديد

أضف عنصرًا إلى `window.SITE_EXAMS` في `assets/js/data-quizzes.js`. عدد الأسئلة
يحدّد توزيع النقاط تلقائيًا على درجة 10:

```js
{ id: "exam-new", track: "tarakib", title: "…", desc: "…", minutes: 15, questions: [ … ] }
```

## 4) برنامج تعلّم القراءة من الصفر

صفحة مستقلة (`reading.html`) لعشر مراحل متدرّجة، مرتّبة بالترتيب التالي:

| # | المرحلة | المحتوى |
|---|---|---|
| 1 | الحروف مع الفتحة | 27 حرفًا + الفتحة، مع تمييز الفتحة عن المدّ |
| 2 | الحروف مع الكسرة | نفس الحروف بالكسرة، ومقارنتها بالفتحة |
| 3 | الحروف مع الضمة | الحركات الثلاث مجتمعة |
| 4 | التهجي | تقطيع كلمة من ثلاثة حروف ثم وصلها |
| 5 | المدود | الألف والواو والياء |
| 6 | السكون | الحرف بلا حركة داخل المقطع |
| 7 | أل القمرية | إظهار اللام ساكنة |
| 8 | الشدة | الحرف المشدّد = ساكن + متحرك |
| 9 | أل الشمسية | إدغام اللام وتشديد الحرف بعدها |
| 10 | التهجي النهائي | كلمات أطول بمقاطع متعدّدة |

> الألف (ا) غير مشمولة في مراحل الحركات لأنها حرف مدّ، وتُدرَّس في مرحلة المدود.

كل مرحلة تحتوي على: هدف واضح، شرح مختصر بجداول، بطاقات تدريب (حروف أو كلمات)،
وزر «✓ أتقنت» لكل بطاقة، وأسئلة قصيرة بتصحيح فوري وشرح لكل جواب.

- **إتمام المرحلة**: تعليم كل البطاقات + الإجابة إجابةً صحيحة عن جميع الأسئلة
  إلا واحدًا على الأكثر.
- **التقدّم**: يُحفظ في `localStorage` تحت المفتاح `ruwaq:reading`، ويظهر في شريط
  التقدّم وأرقام المراحل. زر «إعادة التدريب» يمسح بطاقات المرحلة الحالية فقط.
- **الصوت**: إن كان في المتصفح صوت عربي (`speechSynthesis`) تُقرأ البطاقة عند الضغط
  عليها. وإلا يظهر تنبيه لطيف «اقرأ بصوتك أنت»، ويعمل كل شيء دون صوت.
- **الرابط المباشر**: `reading.html#stage=r-mudood` يفتح المرحلة المطلوبة.

### إضافة مرحلة أو تعديلها

البيانات في `assets/js/data-reading.js`:

```js
{
  id: "r-new",                 // معرّف لاتيني فريد
  title: "عنوان المرحلة",
  subtitle: "سطر توضيحي",
  goal: "هدف المرحلة",
  haraka: "fatha",             // fatha | kasra | damma (لمراحل الحروف فقط)
  letters: "بتث…",              // أو استخدم words بدلًا منها
  concept: [ { type: "p", text: "…" }, { type: "table", head: [...], rows: [...] } ],
  words: [ { text: "كَلْب", split: ["كَلْ", "ب"] } ]
}
```

وأسئلتها في `window.READING_QUIZ["r-new"]` بنفس صيغة أسئلة التمارين
(`q` و`options` و`answer` و`explain`). أنواع كتل الشرح المدعومة:
`p` / `h3` / `ul` / `ol` / `table` / `note` / `example`.

## 5) الاختبار المنزلي (Word + PDF)

الملفات في `assets/tests/`:

| الملف | الوصف |
|---|---|
| `الاختبار-المنزلي-الوحدة-الأولى.docx` | نسخة Word قابلة للتعديل (4 صفحات) |
| `الاختبار-المنزلي-الوحدة-الأولى.pdf` | نسخة PDF مطابقة (4 صفحات) |
| `الورقة-الأولى.pdf` | الصفحتان 1–2 (نصّ الحضارة المغربية) |
| `الورقة-الثانية.pdf` | الصفحتان 3–4 (نصّ مغاربة العالم) |

توزيع النقاط: خمسة أقسام × نقطتان = **10 نقاط**.

لتحديث الملفات: استبدل ملفات `assets/tests/` بنفس الأسماء، أو غيّر المسارات
في `downloads` داخل `config.js`.

## 6) التشغيل والمعاينة

### الطريقة الأسهل

افتح `index.html` مباشرة في المتصفح. كل الروابط نسبية، والموقع يعمل دون خادم.

> ملاحظة: بعض المتصفحات تمنع `localStorage` على بروتوكول `file://`، فلا تُحفظ أفضل
> النتائج. هذا لا يؤثّر في بقية الموقع.

### خادم محلي (مستحسن)

```powershell
cd "C:\Users\محمد\Documents\Default Project"
python -m http.server 8080
```

ثم افتح: <http://localhost:8080>

بديل إن لم يوجد Python:

```powershell
npx serve .
```

## 7) النشر

الموقع ملفات ثابتة، فيكفي رفع محتوى المجلد كما هو إلى:

- **GitHub Pages**: ارفع الملفات إلى المستودع، ثم فعّل Pages من `Settings → Pages`.
- **Netlify / Vercel**: اسحب المجلد إلى لوحة التحكم، دون أي أمر بناء.
- **استضافة عادية**: ارفع الملفات إلى `public_html` عبر FTP.

تأكّد من الحفاظ على أسماء المجلدات بحروفها الصغيرة (`assets`, `css`, `js`, `img`, `tests`).
أسماء الملفات العربية مدعومة في المتصفحات الحديثة، لكن إن واجهت مشكلة على استضافة قديمة
فاستبدلها بأسماء لاتينية وحدّث `downloads` في `config.js`.

## 8) ملاحظات تقنية

- **RTL**: كل الصفحات `dir="rtl"`، والأنماط مكتوبة بخصائص منطقية (`margin-inline-start`…).
- **الخطوط**: Tajawal للواجهة، Noto Naskh Arabic للنصوص، مع بديل `Sakkal Majalla`.
  تُحمّل من Google Fonts، ويبقى الموقع مقروءًا دون اتصال بالخطوط.
- **بدون تتبّع**: لا تحليلات ولا ملفات ارتباط. النتائج تُخزّن محليًا فقط.
- **إمكانية الوصول**: رابط تجاوز، تسميات `aria`، تركيز مرئي، واحترام `prefers-reduced-motion`.
- **الطباعة**: صفحة الدرس تطبع بلا قوائم أو أزرار (`@media print`).
